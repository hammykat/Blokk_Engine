01 / IN PROGRESS

v0.1.9

In progress

No release date announced

Configuration & build foundations

JSON-based configuration, a reorganized CMake setup, and public thread-control fixes.

  • Fixes: expose SetTargetExecutionTime(double) on EngineCore and implement SetThreadCount(uint32_t).

  • Build: move configuration logic into CMake, split build files, and switch macros to JSON configuration.

  • Reliability: add compiler guardrails for SIMD types and update threading and build documentation.

v0.1.9 is not completed yet. Items above reflect the supplied development log, not a published release.

02 / COMPLETED UPDATES

v0.1.8

Released

September 6, 2026

Cross-platform compatibility

Broader CPU support and more resilient engine foundations.

  • SIMD: add ARM NEON, SSE2 branches, scalar fallbacks, and architecture-aware detection.

  • Threading: reuse persistent workers, improve workload handling, and clean up workers on shutdown.

  • Rendering & reliability: camera-aware basic culling, stronger platform guards, and fixes for optional-feature configurations.

v0.1.7

Released

September 3, 2026

Rendering & camera overhaul

SDL3 rendering, image-based animation, and camera controls.

  • Rendering: add SDL3 and SDL_image, texture loading, animation frames, and renderer animation functions.

  • Camera: introduce CameraController with position controls and EngineCore access.

  • Architecture: separate animation data from rendering, support optional rendering, and fix integration and dependency issues.

v0.1.6

Released

August 31, 2026

Direct data & object management

Simpler data flow and more reliable object lifecycles.

  • Data flow: remove internal field-update queues in favor of direct object updates.

  • Objects: separate dynamic and static destruction, fix storage swapping and indexing, and add visibility at creation.

  • Internals: improve cleanup, worker initialization order, IndexRange, and rendering offsets.

v0.1.5

Released

August 30, 2026

Adaptive & fixed threading

Configurable worker counts and cleaner visibility culling.

  • Thread control: introduce adaptive timing and fixed-count modes, plus thread-count safety checks.

  • Culling: refactor Basic and Axis implementations and organize SSE2, AVX2, and AVX-512 helpers.

  • Reliability: fix worker-range visibility indexing and improve internal namespace organization.

v0.1.4

Released

August 28, 2026

Camera & lifecycle reliability

Camera movement and more reliable object handling.

  • Camera: add X/Y movement and camera-aware SIMD visibility culling.

  • Fixes: improve object creation, destruction, swapping, and queue cleanup.

  • Release caveat: this version’s camera requires visibility culling; basic-culling camera support arrives in v0.1.8.

v0.1.3

Released

August 24, 2026

Diagnostics & architecture

Better visibility into engine performance and a clearer public API.

  • Diagnostics: add object/thread counts, execution timings, SIMD register size, and target-time control.

  • Architecture: separate update and render operations and improve public API integration.

  • Developer experience: reorganize documentation, add a basic project template, and reduce branching in hot loops.

v0.1.1

Released

August 22, 2026

Visibility culling foundations

Axis Culling and streamlined SIMD processing.

  • Culling: split Basic and Axis Culling, add SIMD dispatch, and improve animation-frame handling.

  • Internals: update index types, CMake visibility files, and requirements documentation.

  • Removed in this release: AVX support, the incomplete Blokk-C transpiler, and NEON support; NEON returns in v0.1.8.

Development, out in the open.
